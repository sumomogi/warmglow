# Warmglow — JDM Export Studio (concept)

A glassmorphism redesign concept for **JDM Export Studio (Warmglow Ltd.)**, a Japanese
used-car exporter based in Hachioji, Tokyo. Single standalone HTML page.

- **Live demo:** see the GitHub Pages link in the repo's About section.
- **Stack:** plain HTML + CSS (Pretendard via CDN), no build step.
- **Design:** light neutral base, warm-orange accent (brand color), selective frosted glass,
  tabular-figure catalogue cards. Real listing photos and live data from the source storefront.
- **Design notes (KR):** [DESIGN.md](DESIGN.md) — why the page looks the way it does, in plain language.

> Design concept / mockup only — not an operational store.
